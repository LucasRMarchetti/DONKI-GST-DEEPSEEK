# Regras permanentes para Continue.dev

- Use o provedor DeepSeek (deepseek-chat) para tarefas de chat e edição.
- Mantenha os comentários em português.
- Siga a estrutura de projeto definida.
- Utilize Python 3.12 e mantenho boas práticas.
- As respostas devem ser claras e diretas, com exemplos quando possível.
- Ao editar HTML, sempre aplicar `escapeHtml` para evitar XSS.
